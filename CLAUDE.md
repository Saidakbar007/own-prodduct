# Сезоны

Продукт: человек ставит цель и проходит личный **сезон** — челлендж на 30/60/90
дней с одним действием в день и фото-доказательством. Волны стартуют по
понедельникам, по воскресеньям — «серия» (итог недели), в финале — Reveal
«до → после».

## Прочитай перед работой

**SEASONS_SPEC.md** в корне — полное ТЗ (продукт, модель данных, алгоритмы,
экраны, фазы). Читай целиком перед началом задачи. Дизайн-система — в
**DESIGN.md** (появится следующим шагом; пока нет — ориентируйся на ui-ux-pro-max
и ui-styling скиллы).

## Стек

Python 3.12, FastAPI, SQLModel, Alembic, Jinja2 + HTMX, PostgreSQL/SQLite.

## Правила работы (SEASONS_SPEC.md §16)

- Работай сам, без лишних вопросов; неоднозначности решай разумно и фиксируй.
- После шага — только связанные тесты; полный набор (pytest + e2e) — в конце фазы.
  Коммит после каждого рабочего шага.
- Каждый экран — e2e на 375px, в светлой и тёмной теме.
- В конце фазы: слить в `master`, пуш, проверить деплой на Render, короткий отчёт
  и список того, что сделать вручную (Neon, токены, переменные Render — сам не
  выполняй).

## История

Старая версия продукта (личности, магазин, боссы недели и т.п.) заархивирована
в ветке `archive/v6` и теге `v6-final`. Это чистая пересборка под новую
концепцию — полезные модули оттуда переносятся по одному и переписываются под
новую модель, когда до них доходит фаза (см. SEASONS_SPEC.md → «Изменения»).
