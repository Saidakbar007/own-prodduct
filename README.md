# Моя жизнь — MVP

Веб-приложение, которое помогает ставить цели, формировать привычки и
не бросать начатое: **Мечта → Цель → Привычки и программы → Ежедневные
отметки → Очки → Уровень**.

Учебный проект (защита в университете).

## Стек

Python 3.11+, FastAPI, SQLModel + SQLite, Jinja2 + HTMX + Tailwind (CDN),
Chart.js (CDN), passlib[bcrypt] для паролей, cookie-сессии через SessionMiddleware (itsdangerous).

## Установка и запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

# 2. Установить зависимости
pip install -r requirements.txt

# 3. (необязательно) настроить .env
copy .env.example .env         # Windows
# cp .env.example .env         # macOS/Linux
# задать свой SECRET_KEY; ANTHROPIC_API_KEY можно оставить пустым

# 4. (необязательно) заполнить демо-данными
python seed.py

# 5. Запустить сервер
uvicorn app.main:app --reload
```

Открыть в браузере: **http://127.0.0.1:8000**

> **Важно при обновлении с версии v1 (тег `v1-mvp`) на v2:** схема БД
> изменилась (новые поля и таблицы), а миграций нет — старый `app.db`
> нужно удалить перед первым запуском v2, иначе будут ошибки
> `no such column`. После удаления просто запусти `python seed.py` заново.

## Демо-вход

После запуска `python seed.py`:

| Логин       | Пароль     | Что внутри                                                  |
|-------------|------------|---------------------------------------------------------------|
| `demo`        | `demo1234` | 3 привычки (серия 30 дней, привычка с пропусками, вредная привычка по дням недели), мечта с целями (одна завершена, одна активная с шагами/программами/дедлайном), достижения, история чата с коучем, 1 друг |
| `friend_demo` | `demo1234` | Друг пользователя `demo` — показывает рейтинг и прогресс друга |

## Тесты

```bash
python -m pytest -q
```

Тесты используют отдельную БД в памяти (SQLite `sqlite://`), реальный `app.db` не трогают.

## Что умеет приложение

- **Регистрация / вход / выход** — пароли хранятся только как bcrypt-хеш; защищённые страницы редиректят на `/login`, если пользователь не вошёл.
- **Профиль** — вес, рост, семейное положение.
- **Привычки** — создание (тип полезная/вредная, частота каждый день/по дням недели, сложность легко/средне/сложно), отметка «выполнено сегодня», streak, календарь-сетка за 30 дней. Антиобман: очки по сложности и время отметки считает только сервер, отметить привычку можно один раз в день.
- **Мечты и цели** — мечта — цель верхнего уровня; у целей — дедлайн (не в прошлом), шаги с прогресс-баром, история отметок прогресса и завершение.
- **Программы** — тренировочные (Training) и образовательные (Education) программы, привязанные к цели.
- **Очки и уровни** — очки по сложности действия; уровень растёт по порогам: Новичок (0) → Ученик (100) → Практик (300) → Мастер (700) → Легенда (1500). XP-бар виден в шапке на всех страницах.
- **Достижения** (`/achievements`) — 6 значков за разные успехи (первая привычка, серии 7/30 дней, первая цель, первый друг, 100 отметок); всплывающее уведомление при получении.
- **Ежедневные задания** — 3 случайные мини-задачи в день с бонусными очками.
- **Друзья** — заявка → принятие/отклонение, рейтинг по очкам за неделю.
- **Статистика** (`/stats`) — графики (отметки за 30 дней, очки по неделям) и карточки (лучшая серия, всего отметок, целей выполнено, % выполнения за неделю).
- **AI-коуч** (`/coach`) — чат с сохранённой историей; в MVP советует по простым правилам, а если в `.env` задать `ANTHROPIC_API_KEY` — использует Claude API (с откатом на заглушку при ошибке).
- **Дашборд на главной** — сегодняшние привычки, XP-бар, ежедневное задание, ближайшие дедлайны, последнее достижение.

Полный список решений, принятых самостоятельно при неоднозначностях — в [DECISIONS.md](DECISIONS.md).
