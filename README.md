# Моя жизнь — MVP

Веб-приложение, которое помогает ставить цели, формировать привычки и
не бросать начатое: **Мечта → Цель → Привычки и программы → Ежедневные
отметки → Очки → Уровень**.

Учебный проект (защита в университете).

## Стек

Python 3.11+, FastAPI, SQLModel + SQLite, Jinja2 + HTMX + Tailwind (CDN),
passlib[bcrypt] для паролей, cookie-сессии через SessionMiddleware (itsdangerous).

## Установка и запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

# 2. Установить зависимости
pip install -r requirements.txt

# 3. (необязательно) настроить .env
copy .env.example .env         # Windows
# cp .env.example .env         # macOS/Linux
# задать свой SECRET_KEY; ANTHROPIC_API_KEY можно оставить пустым

# 4. (необязательно) заполнить демо-данными
python seed.py

# 5. Запустить сервер
uvicorn app.main:app --reload
```

Открыть в браузере: **http://127.0.0.1:8000**

## Демо-вход

После запуска `python seed.py`:

| Логин       | Пароль     | Что внутри                                                  |
|-------------|------------|---------------------------------------------------------------|
| `demo`        | `demo1234` | 2 привычки (одна с серией 3 дня), мечта с целями (одна завершена, одна активная с дедлайном и программами), 1 друг |

## Тесты

```bash
python -m pytest -q
```

Тесты используют отдельную БД в памяти (SQLite `sqlite://`), реальный `app.db` не трогают.

## Что умеет приложение

- **Регистрация / вход / выход** — пароли хранятся только как bcrypt-хеш; защищённые страницы редиректят на `/login`, если пользователь не вошёл.
- **Профиль** — вес, рост, семейное положение.
- **Привычки** — создание, отметка «выполнено сегодня», streak (серия дней подряд). Антиобман: время отметки ставит сервер, отметить привычку можно только один раз в день.
- **Мечты и цели** — мечта — это цель верхнего уровня, к ней привязываются обычные цели с дедлайном; есть история прогресса и завершение цели.
- **Программы** — тренировочные (Training) и образовательные (Education) программы, привязанные к цели.
- **Очки и уровни** — за отметку привычки и завершение цели начисляются очки; уровень растёт по порогам: Новичок (0) → Ученик (100) → Практик (300) → Мастер (700) → Легенда (1500). Страница `/stats` показывает прогресс.
- **Друзья** — заявка → принятие/отклонение, видно уровень и лучший streak друга.
- **AI-коуч** (`/coach`) — в MVP выдаёт совет по простым правилам; если в `.env` задать `ANTHROPIC_API_KEY`, использует Claude API (с откатом на заглушку при ошибке).
- **Дашборд на главной** — сегодняшние привычки с быстрой отметкой, уровень, ближайшие дедлайны целей.

Полный список решений, принятых самостоятельно при неоднозначностях — в [DECISIONS.md](DECISIONS.md).
