# Моя жизнь — MVP

Веб-приложение, которое помогает ставить цели, формировать привычки и
не бросать начатое: **Мечта → Цель → Привычки и программы → Ежедневные
отметки → Очки → Уровень**.

Учебный проект (защита в университете).

## 🌐 Сайт

**https://own-prodduct.onrender.com**

> Бесплатный тариф Render «засыпает» без активности и просыпается
> ~30-60 секунд на первый запрос — это нормально, не ошибка.
> На этом же тарифе база данных не постоянна: при перезапуске сервиса
> она создаётся заново и автоматически заполняется демо-данными.

На лендинге есть кнопка **«Попробовать демо»** — заходит под демо-аккаунтом
в один клик, без регистрации. Приложение можно установить на телефон как
PWA (есть иконка и офлайн-оболочка), поддерживает тёмную тему (переключатель
в шапке: светлая / тёмная / как в системе).

### Демо-вход

| Логин         | Пароль     | Что внутри                                                  |
|---------------|------------|---------------------------------------------------------------|
| `demo`        | `demo1234` | Привычки с 30-дневной серией, фото-доказательствами и честным пропуском, мечта с целями (шаги, программы, дедлайн), достижения, ставка, напарник, история чата с коучем |
| `friend_demo` | `demo1234` | Друг пользователя `demo` — показывает рейтинг, напарника и ленту подтверждений |

## Стек

Python 3.11+, FastAPI, SQLModel + SQLite, Alembic (миграции), Jinja2 + HTMX + Tailwind (CDN),
Chart.js (CDN), passlib[bcrypt] для паролей, cookie-сессии через SessionMiddleware (itsdangerous).

## Что умеет приложение

- **Регистрация / вход / выход** — пароли хранятся только как bcrypt-хеш; защищённые страницы редиректят на `/login`, если пользователь не вошёл.
- **Профиль** — вес, рост, семейное положение, trust score.
- **Привычки** — тип (полезная/вредная), частота (каждый день/по дням недели), сложность (легко/средне/сложно — очки считает только сервер), календарь-сетка за 30 дней.
- **Честность** — кнопка «Не сделал» (честный пропуск, +2 очка, серию не рвёт); заморозка серии (2 пропуска в неделю без вреда для streak); фото-доказательство с камеры; подтверждение отметки другом («Подтвердить» / «Правда?»); **trust score** (0-100) — множитель очков по доле подтверждённых отметок.
- **Мотивация** — минимальная версия привычки «на плохой день»; мягкий экран возврата после пропуска; адаптивный план (коуч предлагает урезать нагрузку, если выполнение <50% за неделю); напарник (общая серия с другом); ставка очков на серию; сундук — случайная награда за неделю без пропусков; прогресс к мечте в %.
- **Мечты и цели** — мечта — цель верхнего уровня; у целей — дедлайн (не в прошлом), шаги с прогресс-баром, история прогресса.
- **Программы** — тренировочные (Training) и образовательные (Education), привязанные к цели.
- **Очки и уровни** — XP-бар в шапке на всех страницах; уровень растёт по порогам: Новичок (0) → Ученик (100) → Практик (300) → Мастер (700) → Легенда (1500).
- **Достижения** (`/achievements`) — 6 значков; всплывающее уведомление при получении.
- **Ежедневные задания** — 3 случайные мини-задачи в день с бонусными очками.
- **Друзья** — заявка → принятие/отклонение, рейтинг по очкам за неделю, лента отметок для подтверждения.
- **Статистика** (`/stats`) — графики (отметки за 30 дней, очки по неделям), карточки, «ты месяц назад vs сейчас».
- **AI-коуч** (`/coach`) — чат с сохранённой историей; работает по правилам, а с `ANTHROPIC_API_KEY` в `.env` — через Claude API.
- **Дашборд на главной** — привычки на сегодня, XP-бар, ежедневное задание, дедлайны, последнее достижение, прогресс мечты.
- **Лендинг для гостя** — герой, «как это работает», функции, блок про честность, демо-кнопка; гость не видит разделов приложения в навигации.
- **Онбординг** — 4 коротких экрана после регистрации (зачем приложение → мечта → первая привычка → готово), пропускаемый в любой момент.
- **Тёмная тема** и **иконки Lucide** во всём интерфейсе; **PWA** (manifest + service worker + иконка) — можно установить на телефон.

## Для разработки (локальный запуск)

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

pip install -r requirements.txt

copy .env.example .env         # Windows; задать свой SECRET_KEY
uvicorn app.main:app --reload
```

Открыть **http://127.0.0.1:8000** — при первом запуске миграции применятся
и демо-данные заполнятся автоматически (база пустая). Чтобы пересобрать
базу с нуля (бэкап → пересоздание → seed): `python reset_db.py`.

### Тесты

```bash
python -m pytest -q
```

Тесты используют отдельную БД в памяти (SQLite `sqlite://`), реальный `app.db` не трогают.

### Деплой

`render.yaml` в корне — Render подхватывает его как Blueprint (миграции
и seed-на-пустую-базу выполняются автоматически при каждом старте,
`SECRET_KEY` генерируется Render'ом).

Полный список решений, принятых самостоятельно при неоднозначностях — в [DECISIONS.md](DECISIONS.md).
