# NewLife

Бесплатное приложение саморазвития для студентов 18–25 лет в Узбекистане.
Знакомство кнопками (без единого текстового поля) → точка А по 11 сферам
жизни (тело, энергия, разум, знания, карьера, характер, социальное,
финансы, отношения, образ жизни, ценности) → 1–3 цели → расписание недели
вокруг учёбы, работы и сна → ежедневные действия и привычки → сезон на
30/60/90 дней с финальным Reveal «до → после».

Работает как веб-приложение (PWA) и как Telegram Mini App с ботом,
который напоминает утром и подводит итог вечером. Русский и узбекский
языки. Бесплатно.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить SECRET_KEY
uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000. Демо-аккаунт: `python scripts/seed_demo.py`.
