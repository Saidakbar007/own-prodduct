# Решения, принятые самостоятельно (автономный режим)

- Защита страниц: единая зависимость `require_user` в `app/auth.py` — если нет сессии, отдаёт 303 редирект на `/login`.
- Регистрация создаёт сразу 3 записи: `registration` (с хешем пароля), `users` (профиль) и `level` (точка отсчёта 0 очков) — иначе у нового пользователя не было бы уровня для начисления очков.
- Все datetime-поля хранятся как timezone-aware (UTC) — новая версия SQLAlchemy/SQLModel требует это для корректной сериализации, `datetime.utcnow()` без таймзоны выдавал ошибку.
- Streak считается от последней фактической отметки назад по дням подряд; если последняя отметка была более суток назад — streak = 0. Если сегодня ещё не отмечено, но вчера было — streak не сбрасывается мгновенно.
- "Streak друга" (для страницы друзей) = наибольший текущий streak среди всех привычек этого пользователя (а не отдельно по каждой привычке).
- Мечта хранится как запись в таблице `goals` с `parent_id = None`; обычные цели — с `parent_id` = id мечты. Счётчик `users.goals` увеличивается при создании и мечты, и цели (это одна таблица).
- Программы (Training/Education) создаются через отдельный роутер `app/routers/programs.py`, но отображаются на странице цели (`app/routers/goals.py` → `goal_detail`), т.к. визуально относятся к одной цели.
- AI-коуч по умолчанию — заглушка на основе простых правил (нет привычек / нет серии / серия ≥ 7 дней). Если в `.env` задан `ANTHROPIC_API_KEY`, используется реальный вызов Claude API (`claude-haiku-4-5-20251001`); при любой ошибке API — тихий откат на заглушку, чтобы страница коуча не падала.
- `bcrypt` зафиксирован на версии `4.0.1` по прямому указанию пользователя (несовместимость `passlib` с `bcrypt` 5.x).
- Дедлайны на дашборде главной: показываются только незавершённые цели с заданным дедлайном, ближайшие 5, по возрастанию даты.
