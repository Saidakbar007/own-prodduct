## Критерии приёмки 2.0 (из NEWLIFE_2_0.md, копия для отметок)
- [ ] Любая страница на проде < 1 с; сервис и БД в одном регионе; таблица «до → после» в отчёте
- [ ] Вкладка «Цели» открывается мгновенно
- [ ] После входа анкета не повторяется никогда; сессия живёт 90 дней; в Telegram вход автоматический
- [ ] Разные ответы дают разную точку А (тест)
- [ ] У каждого вопроса есть `affects`; вопросов без влияния ноль (тест)
- [ ] Режим дня и обязательные дела спрашиваются один раз; меняются в Профиле с пересчётом плана
- [ ] Расширенный список ограничений, каждое меняет план (constraints.yaml + тесты)
- [ ] После точки А показан реальный потенциал 30/60/90 по протоколам
- [ ] Тур по интерфейсу после анкеты; повтор из Профиля
- [ ] Навбар: Главная · Цели · Привычки · Прогресс · Профиль
- [ ] Главная: дерево сфер с аватаром, живая паутинка, привычки со стриками/таймером, недельная продуктивность с цветом
- [ ] Цели: 11 сфер → 4–8 сезонов из базы знаний → карточки референса 2 → роудмап с «Ты здесь»
- [ ] Тест уровня при старте сезона только про сезон; стартовая неделя зависит от ответа
- [ ] Алгоритм плана: окна/бюджет/ограничения/адаптация; тесты ≥90%
- [ ] Быстрая навигация: закреплённый навбар, переключатель, шторка по свайпу
- [ ] Привычки: добавить/убрать, внедрить/удержать, вредные с таймером, мотивация дня
- [ ] Прогресс: графики + потенциал «при темпе / по плану»
- [ ] Профиль со всеми настройками 3.5
- [ ] Неоновые иконки 11 сфер, лицензии в CREDITS
- [ ] Старые картинки/персонажи удалены; новые фото живые, лицензии в CREDITS
- [ ] Админ-панель 8 разделов, редактирование сезонов, песочница плана
- [ ] pytest + e2e зелёные
- [ ] Лишние экраны удалены (тег pre-v2, список в отчёте)
- [ ] Тег v2.0, деплой, RELEASE_2.0.md
