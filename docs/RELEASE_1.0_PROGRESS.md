      регистрации и не передавался при `/onboarding/start` — любая цель не из
      "Тело" создавалась без привязки к сфере. `/onboarding/goal` теперь
      фильтрует карточки по выбранным сферам (было: показывал всё без разбора)

      нарушал "только кнопки") — `anthropic` убран из зависимостей
- [x] Найден и исправлен баг: создание сезона (регистрация и

      пользователя) — для пользователей восточнее UTC день 1 сезона мог
      молча пропускаться в определённые часы. См. DECISIONS.md.
