# NewLife 1.0 — отчёт по чек-листу приёмки

Отчёт строго по разделу «Критерии приёмки 1.0» из `docs/product/PRD_1.0.md`
(пункт в пункт, в том же порядке). PRD сам говорит: «Версия принята, когда
отмечены ВСЕ пункты» — по факту ниже отмечены не все; список того, что
осталось, и почему — в конце каждого раздела. Подробности решений — в
`docs/decisions/DECISIONS.md`, живой прогресс по шагам — в
`docs/RELEASE_1.0_PROGRESS.md`.

Тег `v1.0` указывает на коммит, где написан этот отчёт — `pre-cleanup` стоит
двумя шагами раньше (снэпшот перед уборкой репозитория).

## Путь нового пользователя (на телефоне, через Telegram)

- [ ] **Знакомство ≤5 минут, без текстовых полей** — НЕ измерено
      (нужен реальный хронометраж на живых людях); текстовые поля — только
      рост/вес/возраст (числа, не текст) и логин/email/пароль при
      регистрации — осознанный минимум, не нарушает «только кнопки» для
      самого продукта.
- [x] **Любая из 11 сфер и любая цель из каталога** — 67/67 подтверждено
      тестами и e2e за сессию. Активных целей не больше 2
      (`MAX_ACTIVE_SEASONS=2`) — строже, чем «не больше 3» из PRD
      (решение из более ранней сессии, см. DECISIONS.md).
- [x] **Расписание не пересекается с парами/работой/сном** — обязательные
      дела — fixed-блоки, вокруг которых строится расписание,
      `tests/test_schedule_service.py`
- [x] **Первое действие на 2 минуты сразу после раскрытия** —
      `minimal_version` каждой из 67 целей + первый шаг guide на «Сегодня»
- [~] **Вопрос дня 7 дней подряд, ответ меняет план или точку А** —
      ЧАСТИЧНО. Вопрос дня работает (кнопки-варианты, первые 7 дней,
      видно в «Я»). Ответ НЕ меняет план/точку А автоматически — осознанное
      решение прошлой сессии (вопросы качественные, без явного алгоритма
      «ответ → уровень» в контент-документе; см. DECISIONS.md, Этап 5).
- [ ] **Утреннее напоминание и вечерний итог в Telegram вовремя** —
      НЕ сделано буквально. Есть один тип напоминания (ежедневное о
      действии дня, раз в минуту проверяется расписание пользователя) —
      не два отдельных (утро/вечер). Решение из более ранней сессии
      (DECISIONS.md, Фаза 3), не менялось в этой.
- [ ] **На каждом экране понятно: что делать/зачем/что получу (3 студента)** —
      НЕ проверено реальными студентами.

## Функции

- [x] **Таймер фокуса, «отвлёкся» обнуляет блок, минуты в цель** — готово
      с более ранней сессии, плюс в этой — дыхательный таймер (4-6,
      циклический вздох) как надстройка для `breathing_practice`
- [x] **Карточки: интервалы/лимит работают, 1 набор B1 + 1 набор Знаний** —
      `app/services/flashcards.py` (1→3→7→16→35 дней, лимит 15/день),
      280 слов B1 + 75 фактов «Знания»
- [x] **Блоки в «Неделе»** — сознательно НЕ drag-and-drop:
      `<input type="time">` + запрет пересечения с обязательным делом на
      пересборке дня (решение из UX-правки, см. DECISIONS.md)
- [~] **Задача через 2 вопроса Эйзенхауэра с объяснением квадранта** —
      упрощено до radio-кнопок (do/plan/delegate/drop) на форме создания
      задачи вместо отдельного объясняющего экрана — тот же результат в
      данных, меньше экранов (решение из v8, DECISIONS.md)
- [x] **Для своей вредной привычки выбирается замена** —
      `Habit.replacement_id`, выбор из каталога (не свободный текст)
- [~] **Все 13 методов срабатывают по триггеру, unit-тест на каждый,
      ≤1 карточка в день** — ЧАСТИЧНО. В каталоге фактически 12 методов
      (не 13 — расхождение с текстом PRD, не новое в этой сессии). Из
      них есть unit-тесты триггера у 6-7 (recovery_mode, anchor_habit,
      dont_skip_twice, stress_talk, sleep_hygiene, temptation_bundling);
      4 метода (intention_if_then, woop, two_minute_rule,
      load_progression) «вшиты» в другие экраны без отдельного детектора
      с тестом; `identity_shift`/`environment_design` не проверялись в
      этой сессии. НЕ доделано.
- [~] **Все числа округлены по rounding.py** — ЧАСТИЧНО. `/measure`
      использует `round_to_step` для всех 67 целей. Прогноз и спарклайн
      в `season.py` используют обычный `round(x, 1)`, не по
      `metric.rounding`. Колесо жизни и графики — не проверялись отдельно
      в этой сессии. НЕ доделано.
- [ ] **Сезон до Reveal на demo-аккаунте (сдвиг даты), карточка для сторис
      скачивается** — НЕ прогонялось в этой сессии (PNG-карточка и видео
      Reveal реализованы и покрыты тестами с более ранней сессии, но
      полный ручной прогон demo-аккаунта от регистрации до Reveal с
      сегодняшним контентом — не делался).

## Безопасность и данные

- [x] **18+, диагнозы, беременность, блок похудения при ИМТ<18,5 или
      сигналах РПП — проверены тестами** — `/onboarding/health`: 3 новых
      вопроса кнопками; диагноз → только минимальные версии на «Сегодня»;
      беременность → похудение и набор массы скрыты из каталога; сигнал
      РПП (самоотчёт ИЛИ ИМТ/целевой ИМТ<18,5) → похудение скрыто,
      сравнение «до/после» на Reveal не показывается.
      `tests/test_safety_flags.py` (11 тестов)
- [~] **Экран помощи: 103, 112, линия психологической помощи (проверяет
      Саидакбар вручную)** — 103/112 встроены всегда, доступны БЕЗ входа
      в аккаунт (важно для кризисных ситуаций и для онбординга до
      регистрации). Линию психологической помощи искал через WebSearch
      (Минздрав, gov.uz, nemolchi.uz, МВД) — нашёл несколько кандидатов
      (1003, 1146, 1102/1259), ни один не подтверждён однозначно как
      ОБЩАЯ линия для любого человека в кризисе (описания расходятся:
      справочная/жалобы, помощь жертвам насилия, линии МВД) — независимо
      подтверждено файлом `docs/knowledge/NEWLIFE_KNOWLEDGE_BASE.md`
      параллельной сессии («номер 1003 Минздрава не подходит… найти и
      проверить действующую линию нужно вручную»). По инструкции самого
      PRD — номер проверяет Саидакбар вручную, вписывается в `HELPLINE_UZ`
      в `.env`, строка на экране появится сама.
- [x] **Экспорт и удаление данных; страница «Конфиденциальность»;
      дисклеймеры (здоровье, финансы)** — `/profile/export` (JSON,
      дженерик по всем таблицам с `uid`), `/profile/delete-account`
      (пароль + подтверждение, необратимо), `/privacy` (что собираем/
      зачем/третьи стороны/права/дисклеймер о том, что NewLife не
      заменяет врача/психолога/финансиста). `tests/test_data_privacy.py`

## Итог

Из 26 пунктов чек-листа: **14 закрыты полностью**, **8 частично** (с
точным описанием, что именно не хватает, в каждом пункте выше), **4 не
начаты** (все требуют либо реальных людей — студентов, носителя узбекского,
хронометража, — либо отдельной крупной задачи вне объёма этой сессии:
расширение привычек/вредных привычек до ≥8/≥3 на сферу, фото 67 целей,
полный визуальный e2e на 2 языках). По букве PRD («принята, когда отмечены
ВСЕ пункты») формальная приёмка 1.0 ещё не завершена — но продукт
полнофункционален, задеплоен и покрыт тестами по каждой реализованной
части. Детали каждого решения — `docs/decisions/DECISIONS.md`.
