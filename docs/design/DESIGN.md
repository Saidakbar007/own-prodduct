# Сезоны — дизайн-система

Направление для продукта, описанного в SEASONS_SPEC.md (§1, 2, 7, 8, 10).
Живые токены и компоненты — в `design/` (`/design`, `/design/screens`).

## Настроение

Премиальное мобильное приложение, которое хочется показывать в сторис: смесь
постера к сезону сериала и спортивной трансляции. Тёмный фон как кинозал,
один уверенный тёплый акцент вместо градиентного шума, крупные уверенные
цифры (день 12 из 30), фото-доказательства как кадры, а не как иконки
трекера привычек. Ощущение «я в середине своего сезона», а не «я выполняю
чек-лист».

## Принципы

1. **Один тёплый акцент, а не два холодных.** Янтарный «glow» — единственный
   голос бренда; бирюзовый — рабочий второй цвет для состояний, не для бренда.
   Без фиолетово-синих дуо-тонов — это язык SaaS-лендингов, не этого продукта.
2. **Тёмный фон — кинозал, не OLED-чернота.** Фон тёплый графитовый
   (`#15120F`), не чистый `#000`: на нём 3D-арт героя и фото выглядят живыми,
   а не выжженными.
3. **Цифры — герои экрана.** «День 12 из 30», проценты, результат замера —
   крупный дисплейный шрифт, трекинг чуть сжат, как на спортивном табло.
   Текст вокруг — тихий и убирается на второй план.
4. **Статус — цвет + форма + слово, никогда только цвет.** Шесть состояний
   дня сезона различаются и оттенком, и иконкой/паттерном, и подписью —
   обязательное условие для WCAG и для дальтоников.
5. **3D, не 2D-мультяшность и не пиксель-арт.** Единственный иллюстративный
   язык — существующий 3D-арт героя (`assets/art/hero/`). Никаких плоских
   мультяшных значков, никакого RPG-инвентаря, сундуков, пиксель-арта —
   это главное визуальное отличие от Habitica и трекеров привычек.
6. **Углы спокойные, не шарообразные.** Радиус 16–20px на карточках — твёрдо,
   по-спортивному; выраженное скругление (pill) — только у бейджей, кнопок и
   нижней панели, не у всего подряд.
7. **Движение — отклик, а не украшение.** Один-два элемента анимируются на
   действие («Сделал» = вспышка-glow + лёгкий масштаб), не весь экран.
   `prefers-reduced-motion` отключает всё, кроме мгновенной смены состояния.

## Чего избегаем

- Фиолетово-синих градиентов на белом фоне — родовой штамп AI/SaaS-лендингов.
- Inter как единственного шрифта — узнаваемый «дефолт», ощущение шаблона.
- Плоской мультяшной графики и аниме-стиля — конфликтует с 3D-артом героя.
- Эстетики Habitica/RPG-трекеров: пиксель-арт, сундуки, игровые панели HP/MP.
- Одинаковых карточек с одной и той же тенью на каждом блоке экрана.
- Неонового киберпанка и пурпурных «ауро»-градиентов — это не спортивный тон.

## Шрифты

**Unbounded** (дисплей: трейлер, «День N из 30», заголовки серий/Reveal) +
**Golos Text** (интерфейс и тело текста). Оба — вариативные шрифты с полной
поддержкой кириллицы и латиницы (включая `cyrillic-ext`, `latin-ext`, то есть
узбекские `oʻ`/`gʻ`), оба явно спроектированы для кириллицы как родной
письменности — в отличие от Inter/Manrope/Space Grotesk, где кириллица —
догонка. Unbounded даёт геометричный, чуть футуристичный характер постера
сезона без скатывания в неоновый киберпанк; Golos Text — тёплая, нейтральная
гарнитура для длинных интерфейсных строк и локализации.

## Цвет

Тёплый графитовый фон вместо чистого чёрного — на нём 3D-арт и фотографии
не "режут глаз" контрастом, а выглядят как кадр фильма. Единственный акцент —
янтарный (`#FFB648`, «glow-up» в буквальном смысле): тепло, уверенно, не
конкурирует с синими соцсетевыми брендами. Бирюзовый (`#1FBE8C`) — второй,
более холодный цвет для статуса «сделано» и позитивных состояний серии,
создаёт контраст тёплого/холодного без ухода в фиолетово-синий штамп.
Статусы дня — шесть различимых оттенков с собственной формой иконки (см.
`design/tokens.css` → `--status-*`), чтобы ни одно состояние не читалось
только по цвету.
