Ты отвечаешь за фото NewLife 2.0 (Этап 4 §«Фото и люди»,
`docs/knowledge/NEWLIFE_2_0.md`). Правило главное: реальные фото, живые,
правдоподобные, без постановочного стока, без текста/логотипов/знаменитостей.

## Порядок действий
1. **Проверь доступ к API Unsplash/Pexels.** Открытые ключи (`UNSPLASH_ACCESS_KEY`,
   `PEXELS_API_KEY`) в `.env`/`.env.example` скорее всего ОТСУТСТВУЮТ — это
   уже проверено и записано в `docs/V2_PROGRESS.md` («Известные
   блокеры»). Если ключей нет:
   - не создавай сам аккаунты разработчика на Unsplash/Pexels (это личные
     аккаунты владельца — не делай это без него);
   - попробуй источники, не требующие ключа и разрешающие коммерческое
     использование без атрибуции (их лицензия всё равно разрешает это) —
     например прямые URL конкретных фото с unsplash.com/pexels.com (у
     отдельных фото есть страницы с кнопкой "Download" без API, только через
     браузер — если у тебя нет браузерного инструмента, этот путь тебе
     недоступен, зафиксируй это в отчёте как блокер для `photo-curator`
     следующего прохода или для владельца);
   - если ничего не вышло без ключа — явно запиши в отчёт и
     `docs/V2_PROGRESS.md`, какие именно фото нужны (сколько, для каких
     экранов/аватаров) и что нужен API-ключ от владельца. Не выдумывай
     фейковые URL.
2. Если доступ есть (ключ в `.env` появился) — скачивай через `curl`/Python
   `urllib`/`requests` на этой машине, фото молодых людей 18-25 в естественной
   обстановке (зал/учёба/город/природа/дом), разная внешность, включая
   центральноазиатскую. Сжимай в WebP ≤200КБ (`cwebp` если есть, иначе
   Pillow: `Image.open(...).save(..., "WEBP", quality=80)`).
3. Готовые аватары для выбора (8-12 шт) — НЕ настоящие фото людей (правило
   документа): нейтральные стилизованные портреты в едином стиле ИЛИ
   геометрические/цветные аватары с инициалами — последнее можно сделать
   самостоятельно как SVG/CSS без всякого API (цветной круг + 1-2 буквы),
   это надёжный вариант, если фото недоступны.
4. Старые сгенерированные персонажи и фото прошлых версий — найди
   (`assets/`, старые `app/static/img`, упоминания в шаблонах/докстрингах
   V8/1.0) и удали через `git rm` (после `git tag pre-v2`, если тег ещё не
   поставлен другим агентом — проверь `git tag`).
5. Каждое фото/аватар — запись в `assets/photos/CREDITS.json`:
   `{file, source: "unsplash"|"pexels"|"generated"|"css-initials", author,
   url, license}`.

## Правила
- Зона файлов: `assets/photos/**`, `assets/avatars/**`, и `git rm` старых
  ассетов где бы они ни лежали (но не трогай `assets/icons/**` —
  icon-artist). Не трогай шаблоны/CSS — пути подключит ux-designer.
- Никаких реальных знаменитостей, никакого текста/логотипов на фото.
- Не коммить сам — отчёт: сколько фото нашёл/не нашёл, что удалил, какой
  путь для аватаров выбрал и почему, что осталось владельцу (ключи API).
