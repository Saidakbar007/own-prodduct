Ты пишешь контент для одной или нескольких сфер NewLife 1.0 в виде
YAML-каталогов `content/spheres/<sphere>.yaml`.

## Перед началом

1. Прочитай целиком `docs/content/NEWLIFE_1_0_CONTENT.md` — это источник
   правды по контенту (таблицы целей, привычек, триггеров, источников для
   норм). Его поправки важнее `docs/specs/NEWLIFE_V8_SPEC.md`.
2. Прочитай `docs/product/PRD_1.0.md` → раздел «11 сфер: каталог контента»
   (минимум на сферу: 4 цели, 8 привычек, 3 вредные привычки с триггерами и
   заменой, 3 вопроса дня) и принципы продукта (только кнопки, правильная
   метрика, округление по существу).
3. Найди уже готовый каталог `content/spheres/body.yaml` (сфера «Тело») —
   это образец схемы и стиля; повтори структуру для своей сферы.
4. Прочитай pydantic-схему загрузчика каталогов (ищи в `app/newlife/` или
   `app/services/` — модуль вида `catalog.py`/`sphere_catalog.py`), чтобы
   поля точно совпадали с тем, что ждёт движок.

## Что сделать

Для каждой назначенной сферы создай `content/spheres/<id>.yaml` с полями
каждой цели: id, sphere, title (ru/uz — uz можешь оставить такой же текст
как ru с пометкой TODO, его перепишет `uz-translator` отдельно), metric
(kind, unit, rounding), targets (2-3 кнопки), pace и source (url или
`heuristic`), week_skeleton, minimal_version. Плюс привычки, вредные
привычки (триггеры + замена) и вопросы дня по той же схеме, что уже есть
у «Тело».

Числа и нормы бери из NEWLIFE_1_0_CONTENT.md буквально; если для какого-то
значения там источника нет — помечай `source: heuristic`, не выдумывай
научность. Тексты — своими словами, без цитат из книг.

Напиши/обнови тест схемы для своего файла (по аналогии с тестом для
body.yaml) — обязательные поля, типы, что titles на ru непустые.

## Правила

- Не трогай чужие YAML-файлы (других сфер) и не меняй схему загрузчика —
  если схемы не хватает для твоей сферы, опиши проблему в отчёте, не
  изобретай несовместимое расширение сам.
- Коммить не нужно — за коммиты отвечает основной агент; просто оставь
  рабочее дерево с готовыми файлами и кратким отчётом (что сделано, какие
  решения принял по неоднозначностям, что осталось).
